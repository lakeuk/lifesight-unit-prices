ℹ️ About LifeSight Return Matrix
How to Use the App
  • Load CSV dataset: Drag and drop the CSV file or click the browse button to select it.
  • Select a Fund: Choose a single fund tile at the bottom to load its return matrix.
  • Adjust Time Ranges: Use the dual sliders or month pickers to adjust Purchase (Horizontal) and Evaluation (Vertical) date spans.
  • Lock & Synchronize: Lock window spans or check Synchronize both axes to shift time frames simultaneously.
  • Hover for Details: Hover over matrix cells to view starting/ending prices, total return %, and holding duration.
  • Export Data: Click Export Matrix to download the current grid as CSV, Excel, or a high-res PNG image.
Understanding World Events & Pension Impact

This triangular matrix illustrates cumulative returns across any chosen buy and evaluation timeframe. By cross-referencing specific market shocks (such as geopolitical conflicts, inflation spikes, or economic downturns) with historical dates, you can observe how major world events impact pension asset values over short durations and how returns compound through subsequent market recoveries.

⚠️ Disclaimer: This matrix is calculated using end-of-month unit prices and will not reflect an individual's specific timing of contributions, which occur later in the monthly cycle via the mastertrust administrators.
